# Utility Plus (Minecraft 1.21.1, Fabric)

Needs: Fabric Loader 0.16.10+, Fabric API 0.116.7+1.21.1, Java 21.

## Build without installing anything
1. GitHub: upload this folder to a new repository -> Actions tab -> "build" -> download artifact `utility-plus-jar`.
2. Or locally with JDK 21: run `build.bat` (Windows) or `./build.sh` (Linux/macOS). It downloads its own Gradle. JAR appears in `build/libs/` (use the file without `-sources`).

## Grappling hook
Right-click a block to attach, again (or sneak) to release. Jump pulls you in, Sprint+Jump lets rope out; gravity gives a real pendulum swing.
